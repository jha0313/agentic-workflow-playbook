# 데모에서 실제로 쓴 첫 프롬프트

두 데모 모두 이 여덟 줄이 사람이 준 첫 입력의 전부다. 템플릿의 여섯 칸 중 목표만 채웠고, 나머지는 1번 의도 단계에서 에이전트가 물어서 채웠다. 경로만 각자 환경에 맞게 바꾸면 그대로 쓸 수 있다.

## 비개발 · 로드맵 진척 대시보드 (기획자 페르소나)

```
~/Projects/OnlineLecture/대본/세미나-삼성DX/2차/워크플로우-플레이북.md
를 읽고, 그 안의 "드롭인 조율자 템플릿"대로 행동한다.

나는 AutoKliq의 기획자다. 코드를 쓰지 않고, ~/Projects/autokliq 저장소를 고치지 않는다(읽기는 된다).

목표: AutoKliq의 로드맵 대비 지난 분기 진척을 이해관계자가 파악할 수 있는 대시보드를 만든다.
나머지 5칸(0번 파일 · 5-a · 5-b · 완료 정의 · K)은 1번에서 나에게 물어서 채워라.

- 각 단계가 끝나면 멈추고 내 승인을 기다린다.
- .env 계열 파일을 열지 않는다. 키·토큰이 보이면 <REDACTED>로 쓴다.
```
